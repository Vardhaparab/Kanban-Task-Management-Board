Kanban Task Manager

Organize your tasks like a pro! 📝
A responsive Kanban board with drag-and-drop, task priorities, search, and light/dark mode, built with HTML, CSS, and JavaScript. Save tasks locally and keep your workflow neat and efficient.

Features at a Glance:

✅ Add, edit, delete tasks

⏳ Drag-and-drop between columns

🔍 Search tasks by title or description

🌈 Light/Dark theme toggle

🏷 Priority labels (Low, Medium, High)

💾 Persistent storage with localStorage
